# Diagrams

Lưu sơ đồ ở dạng nguồn có thể chỉnh sửa và, khi cần, kèm ảnh xuất. Các định dạng có thể dùng gồm diagrams.net/draw.io (`.drawio`), SVG và PNG.

Với TASK-003, `use-case-diagram.drawio` là file nguồn có thể chỉnh sửa sau khi được tạo bằng draw.io. `use-case-diagram-reference.svg` là ảnh tham khảo để dựng sơ đồ; phần mô tả actor và use case nằm trong `use-case-diagram.md`.

Bạn có thể vẽ bằng công cụ bên ngoài rồi thêm file vào `docs/diagrams/`. Nên ưu tiên đẩy file nguồn `.drawio`; có thể thêm ảnh xuất cạnh file nguồn với cùng tên cơ sở, ví dụ `use-case-diagram.drawio` và `use-case-diagram.png`. Nếu chỉ có ảnh, thêm PNG/SVG cũng được, nhưng ảnh sẽ không thay thế được nguồn chỉnh sửa.

Quy ước tên ví dụ: `payment-dispensing-sequence.drawio`, `system-architecture.drawio`.
