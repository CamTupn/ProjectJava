# ScentStation

A Multi-Brand IoT Perfume Experience and Management Platform.

## Project Overview

ScentStation is a platform that connects perfume kiosks,
customers, and brand administrators.

## Main Modules

- Backend API
- Web Management Portal
- IoT Perfume Kiosk
- Inventory Management
- Maintenance and Monitoring
